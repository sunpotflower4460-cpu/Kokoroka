# こころか (Kokoroka)

「自然と人間の共生」をテーマに発信するメディアの運用リポジトリ。
YouTube / TikTok / note / Instagram / Threads / ブログへ、1つの素材を多展開する。

## パイプライン

1. **台本作成**（Muse）: `episodes/<ep>/script.md` にナレーション原稿＋画面指示＋タイトル案＋サムネイル文案を書く
2. **自動添削**（GitHub Actions）: 台本を push すると `script-review` ワークフローが走り、自然さ・世界観フィット・フック強度をスコアリングし、断定表現や出典漏れを機械チェックして `episodes/<ep>/review.md` に記録する（SNS-AI の自然化レビューと同じ発想）
3. **制作**（Dots → Codex）: ナレーション生成 → 動画組み立て → サムネイル作成
4. **事実・品質チェック**（Muse）
5. **承認**（オーナー：完成パッケージの承認のみ）
6. **投稿**（Muse：見張り方式／API可能な媒体は自動）
7. **週次レビュー**: 数字を台帳に記録し、伸びた型を次の台本へ反映

## 運営ルール

- 研究・生態の記述は出典を確認し、台本に `出典:` を明記する
- 健康・癒しの効果は断定しない（「〜という研究がある」の形に統一）
- AI生成コンテンツの開示は各媒体のルールに従う
- 規約違反の自動化はしない。外向きの投稿は当面チェックポイント付き

## 構成

- `episodes/` — 各回の台本とレビュー結果
- `review/` — 自動添削スクリプト
- `docs/` — 台本フォーマット等のドキュメント
- `ledger/` — 投稿実績と数字の台帳（週次レビュー用）
