# 台本フォーマット（script.md）

各エピソードの台本は `episodes/<ep>/script.md` に置く。自動添削と制作（Dots→Codex）の両方が読む前提の形式。

```markdown
# タイトル案
（メイン案を1つ、サブ案を最大2つ）

## メタ
- 柱: もしも / 研究・生態 / 暮らしの実践
- 想定尺: 3分
- 出典: （研究・生態の主張がある場合は必須。URLまたは書名）

## ナレーション
（読み上げ原稿。そのまま TTS に渡せる形で。1文は短く）

## 画面指示
（場面ごとに、何が映るか・字幕テキスト・切り替えのタイミング）

## サムネイル文案
（大きな文字で入れる文言と、画のイメージ）

## 展開メモ
（縦型カットの切り出し位置、note/ブログ版の構成、Threads 用の短文）
```

## ルール
- 健康・癒しの効果を断定しない（「治る」「効く」「必ず」等は自動添削で警告される）
- 研究・生態の主張には必ず出典を付ける
- 冒頭3秒で「何の話か＋続きが気になる」フックを入れる
